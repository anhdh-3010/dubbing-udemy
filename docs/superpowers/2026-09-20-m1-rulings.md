# M1 — decisions taken during implementation

Every ruling made while executing `plans/2026-09-20-m1-dubbing-pipeline.md`, in
the order they were made. These are decisions taken on the author's behalf when
the plan was silent, wrong, or self-contradicting. Each records the reasoning and
what it costs if it turns out to be wrong.

The plan supplied complete source for most tasks and implementers were told to
transcribe it verbatim and report rather than silently fix. Most defects below
were therefore in the plan, found by review, and changed only by explicit ruling.

Spec: `specs/2026-09-20-udemy-realtime-dubbing-design.md` — the binding authority
wherever it and the plan disagree.

### 3. Tasks 2+3: Ruling: the plan's "không cắt ở dấu chấm của chữ viết tắt" test is vacuous — deleting `ABBREVIATIONS` from `endsSentence` leaves it passing, so that branch has zero coverage. ### 24. Task 12: Ruling: I AM AMENDING MY OWN RULING 2. I froze the plan's translateBatch verbatim, and that froze a real defect in place. FIX: catch non-auth errors inside the loop and continue; rethrow the last error only if nothing at all was translated, so partial success resolves and total failure still surfaces its cause.
